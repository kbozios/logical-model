Logical Model: Patient model

Official URL: http://ehds.eu/fhir/models/StructureDefinition/EHDSPatient Version: 0.1.0
Draft as of 2026-07-06 Computable Name: EHDSPatient

EHDSPatient means a structured set of data elements describing a subject of care.

Usages:

  • Use this Logical Model: DataSet model, Imaging report model, Medical test result and report model, Medication dispense model... Show 3 more, Observation model, Related person model and Specimen model

You can also check for usages in the FHIR IG Statistics
