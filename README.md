This IG is a sandbox for continuing work with Logical Information Models.

The IG is for COM internal revision during the ongoing regulatory process and does not allow outside contributions at this point.

The temporary build: [https://build.fhir.org/ig/EEHRxF/logical-model](https://build.fhir.org/ig/EEHRxF/logical-model/)  

GitHub Pages build: https://eehrxf.github.io/logical-model/

During the build a Word document with table views of the logical models is generated. The Word document is available as an artefact to the GH_PAGES_BUILD github workflow, see https://github.com/EEHRxF/logical-model/actions/workflows/ghbuild.yml for a list. The artefacts are available for each specific workflow run in the bottom of the page, e.g. https://github.com/EEHRxF/logical-model/actions/runs/25739037813#artifacts. The tables do not provide all information of the models and the online version is recommended for browsing.
