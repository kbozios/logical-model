Logical Model: Medication use model

Official URL: http://ehds.eu/fhir/models/StructureDefinition/EHDSMedicationUse Version: 0.1.0
Draft as of 2026-07-06 Computable Name: EHDSMedicationUse

EHDSMedicationUse means a structured set of data elements describing a use of a single medicinal product as part of a medication summary.

Usages:

  • Use this Logical Model: Discharge Report model, Imaging report model and Patient summary model

You can also check for usages in the FHIR IG Statistics
