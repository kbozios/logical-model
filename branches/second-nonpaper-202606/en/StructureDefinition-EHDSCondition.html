Logical Model: Condition model

Official URL: http://ehds.eu/fhir/models/StructureDefinition/EHDSCondition Version: 0.1.0
Draft as of 2026-07-06 Computable Name: EHDSCondition

EHDSCondition means a structured set of data elements describing a clinical condition, problem, or diagnosis.

Usages:

  • Use this Logical Model: Care plan model, Device use model, Discharge Report model, Encounter model... Show 6 more, Imaging report model, Medical test result and report model, Medication administration model, Patient summary model, Procedure model and Service request model

You can also check for usages in the FHIR IG Statistics
